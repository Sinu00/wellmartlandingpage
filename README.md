# WellMart Winners Club — Landing Page

Animated landing page for the WellMart Winners Club 4-month prize draw, Kasaragod, Kerala.

- `index.html` — the complete page (open directly in a browser)
- `assets/` — web-ready logo and bag-mark PNGs (white and brand pink, transparent)
- `src/page.html` — page body without the document wrapper
- `wellmartS-*.jpeg` — original logo files supplied by the client

Built with plain HTML/CSS and GSAP + ScrollTrigger (loaded from cdnjs). Fonts: Fredoka and DM Sans via Google Fonts.
